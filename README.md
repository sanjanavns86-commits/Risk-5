# Risk-5

## What is RISK-5

A free and open-source instruction set architecture (ISA) based on reduced instruction set computer (RISC) principle. 

## Why RISC-V Matters-

**No Royalties:** Anyone, from students and startups to tech giants, can build chips using RISC-V without paying expensive licensing fees.
**Customizable:** Companies can easily add custom exensions for specialized workloads like artificial intelligence or machine learning without breaking base compatibility
**Open source:** anyone can use this to build there code with no.taxes
**Current ApplicationsEmbedded Systems:** Widely used in hard drives, smartwatches, automotive microcontrollers, and IoT devices.
**Growing Ecosystem:** Major organizations and manufacturers are actively scaling RISC-V toward data centers, aerospace, and high-performance computing.
           
## What is Processor??

A processor, also known as the Central Processing Unit (CPU), is the electronic brain of a computer that executes instructions and performs calculations.
